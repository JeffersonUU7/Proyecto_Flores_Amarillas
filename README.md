# 🌻 Jardín de Código - Proyecto POE

Un proyecto web interactivo de flores amarillas animadas desarrollado con **Next.js**, **React** y **HTML5 Canvas**. Creado por Jefferson para la carrera de Ingeniería en Desarrollo de Software (UNIVO).

## 🌐 Página publicada

Visita la versión desplegada e interactúa con el jardín:

**[Abrir Flores Amarillas](https://proyecto-flores-amarillas-one.vercel.app/)**

En la página, pulsa **Ejecutar Animación** para abrir la experiencia interactiva.

## ⚙️ Requisitos Previos

Asegúrate de tener instalado en tu computadora:
* **Node.js** (versión 18 o superior recomendada)
* **npm** (gestor de paquetes, incluido al instalar Node.js)

---

## 🚀 Cómo ejecutar el proyecto localmente

Sigue estos comandos en tu terminal para levantar la aplicación:

1. **Ubícate en la carpeta del proyecto:**
   ```bash
   cd proyecto_flores_amarillas


Instala las dependencias necesarias (solo se hace la primera vez):

Bash
npm install
Inicia el servidor de desarrollo:

Bash
npm run dev
Abre la aplicación:
Ve a tu navegador web e ingresa a 👉 http://localhost:3000

🛠️ Tecnologías Utilizadas
Next.js 14 (App Router)

React 18

CSS Puro (Flexbox y Animaciones Keyframes)

HTML5 Canvas (Para renderizado interactivo avanzado)
